   PANDUAN LENGKAP MENJALANKAN PORTOFOLIO - DEWAN MOCHAMAD PRATAMA

Folder ini berisi 2 VERSI PORTOFOLIO LENGKAP:
1. VERSI WEB BIASA (HTML5 + Tailwind CSS + JavaScript)
2. VERSI MOBILE ASLI (React Native + Expo SDK 57)

--------------------------------------------------------------------------------
A. CARA MEMBUKA VERSI WEB BIASA (Paling Cepat & Langsung Jalan)
--------------------------------------------------------------------------------
Jika ingin langsung melihat hasil desain di laptop tanpa instalasi/server apa pun:
1. Buka folder ini di File Explorer laptop Anda:
   C:\Users\LENOVO\.gemini\antigravity\scratch\dewan-portfolio
2. Klik 2x (double-click) file: index.html
3. Halaman portofolio akan langsung terbuka di browser (Chrome / Edge).
4. Tampilan sudah 100% responsif (rapi untuk layar HP maupun laptop).

--------------------------------------------------------------------------------
B. CARA MENJALANKAN VERSI REACT NATIVE DI HP (Untuk Presentasi Dosen)
--------------------------------------------------------------------------------
Aplikasi mobile ini dibuat dengan React Native murni (Expo SDK 57) dan sudah
dilengkapi fitur animasi interaktif & simulasi fisika (Spring Physics Lab).

Langkah 1: Koneksi Wi-Fi
- Pastikan HP dan Laptop Anda terhubung ke JARINGAN WI-FI YANG SAMA.
  (IP Wi-Fi laptop Anda sudah otomatis dikunci ke: 192.168.1.13)

Langkah 2: Buka Terminal di VS Code
- Buka folder proyek ini di VS Code.
- Buka Terminal di VS Code (tekan tombol Ctrl + ` atau menu Terminal -> New Terminal).

Langkah 3: Jalankan Perintah Start
- Ketik perintah ini di terminal VS Code, lalu tekan Enter:
  npm start

- Tunggu beberapa detik sampai tulisan "Starting Metro Bundler" dan 
  QR CODE (BARCODE) BESAR muncul di terminal.

Langkah 4: Scan QR Code di HP
- Buka aplikasi "Expo Go" di HP Anda.
- Pilih menu "Scan QR Code".
- Arahkan kamera HP ke barcode yang muncul di terminal laptop.
- Tunggu proses bundling ("Android Bundling... 100%").
- Portofolio React Native Anda akan langsung muncul dan interaktif di layar HP!

--------------------------------------------------------------------------------
C. TIPS & SOLUSI JIKA MENGALAMI KENDALA
--------------------------------------------------------------------------------
1. Jika barcode tidak muncul atau port sibuk:
   - Tekan Ctrl + C di terminal VS Code untuk menghentikan server lama.
   - Ketik `npm start` kembali.

2. Jika aplikasi di HP sempat menampilkan cache lama atau blank:
   - Tutup aplikasi Expo Go di HP (swipe close dari recent apps).
   - Buka kembali Expo Go dan scan ulang barcode-nya.
   - Atau goyang-goyangkan (shake) HP saat di Expo Go, lalu pilih "Reload".

3. Cara melihat versi Web dari React Native di Browser Laptop:
   - Saat terminal `npm start` sedang menyala, cukup tekan tombol huruf `w`
     pada keyboard di terminal tersebut.
   - Browser laptop akan otomatis membuka versi web dari React Native.
