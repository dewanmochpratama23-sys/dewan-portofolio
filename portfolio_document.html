IoT Multi-Sensor Smart Environment & 4-Stage Traffic Light Alert System

Sistem Telemetri Suhu, Kelembapan, dan Deteksi Cahaya Terintegrasi dengan LCD 16x2 I2C & Visual Andon Alert
Hardware Assembly Aktif
Platform: ESP32 / Arduino C++
Ikhtisar Rekayasa: Sistem stasiun telemetri lingkungan dan keselamatan kerja cerdas yang dirancang untuk memantau suhu, kelembapan udara, serta intensitas cahaya ambien secara simultan. Menggunakan mikrokontroler ESP32 32-bit Xtensa Dual-Core berkecepatan tinggi, sistem mengolah data sensor suhu/kelembapan DHT dan sensor cahaya LDR (Light Dependent Resistor), menampilkan metrik pengukuran real-time pada layar LCD 16x2 dengan antarmuka I2C, serta memicu modul lampu Traffic Light 4-Warna (Merah, Kuning, Hijau, Biru) secara otomatis berdasarkan ambang batas termal bertingkat (*multi-stage thermal logic*).

Sub-Sistem Deteksi Cahaya Ambien (LDR) & Display LCD 16x2 I2C
1. Logika Sensor Cahaya LDR (Photodiode): Analog to Digital
  • Pendeteksian Foton Real-Time: Menggunakan sirkuit pembagi tegangan (*voltage divider*) LDR yang dihubungkan ke pin ADC ESP32.
  • Status Deteksi Cahaya Aktif: Saat cahaya menyinari sensor di atas nilai kalibrasi ambang (*threshold*), sistem mengonfirmasi status bahwa sumber cahaya aktif.
  • Feedback Visual LCD: Baris kedua LCD 16x2 secara otomatis menampilkan: Cahaya: AKTIF (ON) ketika terang, dan Cahaya: GELAP (OFF) ketika redup.
2. Layar LCD 16x2 dengan Komunikasi I2C: Bus 2-Kawat
  • Efisiensi Pin Mikrokontroler: Modul PCF8574 I2C adapter memungkinkan layar beroperasi hanya dengan 2 jalur data (SDA D21 & SCL D22), menghemat GPIO ESP32.
  • Tampilan Informasi Terpadu: Menampilkan pembacaan suhu (°C), kelembapan (%RH), dan status sensor cahaya secara bergantian atau simultan tanpa *flicker*.
  • Potensiometer Kontras: Kalibrasi kejelasan teks di lingkungan pencahayaan pabrik yang bervariasi.

IoT Smart Car Reverse Parking Sensor System

Sistem Asistensi Parkir & Mundur Mobil Cerdas Berbasis Mikrokontroler ESP32 32-bit
Hardware Prototype Aktif
Platform: ESP32 / Arduino C++
Ikhtisar Rekayasa: Sistem asistensi keselamatan manuver mundur kendaraan yang dirancang untuk mengeliminasi *blind spot* pengemudi secara real-time. Menggunakan mikrokontroler ESP32 32-bit Xtensa Dual-Core yang dipadukan dengan transduser ultrasonik HC-SR04, sistem menghitung jarak rintangan secara akurat berdasarkan kecepatan rambat suara, memvisualisasikan metrik pada layar LCD Crystal 16x2, memicu lampu LED 3 warna sesuai zonasi risiko, serta memodulasikan frekuensi audio buzzer (PWM) adaptif seiring mendekatnya halangan.

Arsitektur Perangkat Keras & Firmware Berbasis C++
Komponen Fisik & Spesifikasi Pinout:
  • MCU ESP32 (Xtensa LX6): Frekuensi clock hingga 240 MHz, 520 KB SRAM, respons mikrodik detik.
  • Transduser HC-SR04: Pin Trigger (D5) & Echo (D18). Rentang deteksi efektif 2 cm s.d. 400 cm.
  • Layar LCD 16x2 I2C: Komunikasi 2-kawat (SDA D21, SCL D22) hemat pin I/O mikrokontroler.
  • Cluster LED 3-Warna: D19 (Merah), D2 (Kuning), D4 (Hijau) dengan resistor proteksi 220Ω.
  • Piezo Buzzer Transistor Driver: Pin D15 dimodulasikan sinyal gelombang suara proporsional.
Prinsip & Formula Kalkulasi Fisika:

  • Non-Blocking Timing Architecture: Menghilangkan fungsi delay(), menggantinya dengan evaluasi timer millis() non-blocking sehingga pembacaan sensor bebas lag (*zero jitter*).
  • Kesiapan Telemetri IoT (IoT-Ready): Arsitektur modular siap diekspansi untuk pengiriman data jarak nirkabel melalui protokol MQTT/HTTP via Wi-Fi ESP32.

Sistem Presensi & Pengenalan Wajah Otomatis (Face Recognition)

Teknologi: Python 3, OpenCV (Open Source Computer Vision), Tkinter Desktop GUI, NumPy
Desktop AI Software
GitHub Repository
Deskripsi & Konsep Solusi: Perangkat lunak AI berbasis desktop yang mampu mendeteksi wajah secara real-time melalui kamera digital, mengekstraksi titik koordinat fitur wajah (*facial landmark embeddings*), melatih dataset model pengenalan secara mandiri, dan mengidentifikasi identitas pengguna dengan tingkat akurasi tinggi untuk kebutuhan presensi karyawan otomatis tanpa sentuhan (*touchless biometric attendance*).
Alur Kerja Pipeline Machine Vision:
  • 1. Video Capture Real-Time: Inisialisasi streaming kamera webcam frame-by-frame dengan konversi ruang warna grayscale berkecepatan tinggi.
  • 2. Facial Feature Detection: Segmentasi wajah secara otomatis menggunakan Haar Cascade Classifier / Dlib HOG detector.
  • 3. Automated Dataset Gathering: Pengambilan sampel wajah pengguna secara terstruktur (puluhan sudut pencahayaan) ke dalam direktori data.
  • 4. Model Training & Matching: Melatih model pengenal wajah mandiri dan membandingkan matriks histogram untuk menghasilkan skor keyakinan (*confidence level*).
Keunggulan & Nilai Praktis:
  • Antarmuka Ramah Pengguna (GUI): Dibangun menggunakan framework Tkinter desktop yang memudahkan staf operasional mendaftarkan karyawan baru dalam beberapa klik.
  • Kecepatan Identifikasi Cepat: Proses inferensi pengenalan berlangsung dalam waktu kurang dari 500 ms per wajah yang terdeteksi.
  • Pencegahan Kecurangan (Anti-Fraud): Mengurangi risiko titip presensi (*buddy punching*) secara signifikan di area operasional pabrik atau gudang.
