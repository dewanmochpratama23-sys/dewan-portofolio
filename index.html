Computer Vision & AI Desktop App

Sistem Deteksi & Pengenalan Wajah (Face Recognition)

Teknologi: Python, OpenCV, Tkinter GUI, NumPy

Aplikasi kecerdasan buatan berbasis desktop yang mampu mendeteksi wajah secara real-time melalui kamera komputer, mengekstrak fitur biometrik, melatih dataset secara mandiri, dan mengenali identitas individu dengan tingkat akurasi tinggi.

  • Deteksi wajah multi-frame real-time dengan algoritma Haar Cascade / Dlib
  • Perekaman dataset mandiri dan pelatihan model pengenalan otomatis
  • Antarmuka grafis ramah pengguna berbasis Tkinter desktop
