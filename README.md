# Portofolio Pribadi - Dewan Mochamad Pratama 🚀

Aplikasi portofolio pribadi interaktif modern yang dikembangkan menggunakan **React Native (Expo SDK 57)** untuk platform mobile dan didampingi versi **Web Responsif (HTML5 + Tailwind CSS)**.

Dibuat khusus untuk memenuhi tugas portofolio akademik dan demonstrasi rekayasa aplikasi antarmuka pengguna (*UI/UX Engineering*).

---

## 🌟 Fitur Utama

- 📱 **Mobile Native First (React Native):** Berjalan secara native di Android dan iOS menggunakan Expo Go.
- 🪪 **Digital Invitation Cover UX:** Layar pembuka cover interaktif ala undangan digital sebelum masuk ke katalog portofolio.
- ⌨️ **Live Typing Animation:** Efek teks mengetik dinamis untuk perkenalan profesi dan keahlian.
- 🧪 **Laboratorium Fisika Interaktif (Spring Physics Lab):** Simulasi fisika elastis pegas (*spring physics animation*) pada token keahlian saat disentuh.
- 📊 **Progress Bar & Timeline:** Visualisasi keterampilan teknis serta garis waktu perjalanan pendidikan dan eksplorasi teknologi.
- 💬 **Buku Tamu Interaktif (Interactive Guestbook):** Pengunjung dapat mengetik nama, peran, dan mengirim pesan sapaan secara langsung (*real-time local state*).
- 🔗 **Tautan Kontak & Media Sosial Cepat:** Tombol terintegrasi (*deep linking*) langsung menuju WhatsApp, Email, LinkedIn, dan GitHub.
- 🌐 **Versi Web Responsif:** Dilengkapi file `index.html` murni dengan Tailwind CSS untuk tampilan di peramban desktop.

---

## 🛠️ Tech Stack

- **Mobile:** React Native (0.86), React (19.2), Expo SDK 57, Expo Vector Icons
- **Web:** HTML5, Tailwind CSS, FontAwesome, JavaScript (ES6+)
- **Tools & Bundler:** Metro Bundler, Babel, Node.js

## 🚀 Panduan Menjalankan Proyek

### 1. Menjalankan di Perangkat Baru (Setelah Clone dari GitHub)

Jika Anda baru saja meng-clone repositori ini atau baru meng-install ulang laptop:
```bash
# 1. Clone repositori
git clone https://github.com/dewanmochpratama23-sys/dewan-portofolio.git

# 2. Masuk ke folder proyek
cd dewan-portofolio

# 3. Pasang semua dependensi
npm install

# 4. Jalankan server Expo
npm start
```

### 2. Menjalankan Versi Mobile (React Native via Expo Go)

1. Jalankan `npm start` di terminal.
2. Buka aplikasi **Expo Go** di HP (tersedia di Google Play Store & Apple App Store).
3. Pastikan HP dan Laptop terhubung ke Wi-Fi / Hotspot yang sama:
   - *Di Rumah:* Sambungkan ke Wi-Fi rumah yang sama.
   - *Di Kampus / Tempat Umum:* Gunakan Hotspot pribadi dari HP ke Laptop (untuk menghindari blokir keamanan jaringan publik).
4. Scan **QR Code** yang tampil di terminal laptop.
5. Aplikasi akan langsung memuat dan berjalan di HP Anda.

### 3. Menjalankan Versi Web (HTML)

Cukup buka file `index.html` langsung dengan klik dua kali (double-click) untuk membukanya di browser (Google Chrome, Microsoft Edge, dll).
