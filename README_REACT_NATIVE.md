# Dewan Mochamad Pratama - Portfolio (React Native & Web)

Proyek ini memiliki **2 versi portofolio** lengkap di dalam 1 folder:
1. **Versi Web Biasa**: `index.html` (HTML5, Tailwind CSS, Vanilla JS)
2. **Versi Mobile Asli**: `App.js` (**React Native + Expo**)

---

## 📱 Cara Menjalankan Versi React Native di HP (Expo Go)

### Langkah 1: Buka Terminal di Folder Ini
Buka terminal / PowerShell di direktori `dewan-portfolio`.

### Langkah 2: Install Dependencies
Jalankan perintah berikut menggunakan `npm.cmd` (atau `npm`):
```bash
npm.cmd install
```
*(atau jika policy PowerShell Anda mengizinkan: `npm install`)*

### Langkah 3: Jalankan Expo Server
```bash
npx expo start
```

### Langkah 4: Buka di HP Anda
1. Download aplikasi **Expo Go** secara gratis di:
   - **Android**: Google Play Store
   - **iOS**: Apple App Store
2. Pastikan HP dan laptop berada di jaringan Wi-Fi yang sama (atau gunakan opsi tunnel `npx expo start --tunnel`).
3. Scan **QR code** yang muncul di terminal / browser laptop menggunakan kamera HP (iOS) atau aplikasi Expo Go (Android).
4. Aplikasi portofolio React Native Anda akan langsung terbuka dan berjalan secara native di layar HP!

---

## 🌐 Menjalankan Versi React Native di Web Browser
Jika ingin melihat versi React Native ini berjalan di browser laptop:
```bash
npx expo start --web
```

---

## 📄 Tetap Ingin Buka Versi HTML Biasa?
File `index.html` tetap utuh dan tidak diubah. Cukup klik ganda file `index.html` untuk membukanya langsung di browser tanpa perlu server apa pun.
